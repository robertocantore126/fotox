# M0-T04 — Viewport texture and the transparent hole

Agent: Claude  ·  Branch: `task/M0-T04-viewport`  ·  Status: done (merged by Claude)

## Plan (written before coding)

1. `ui/js/native/protocol.js`: framing (`encodeJson`, `encodeBinary`, `decode`) and every message type name from `fx-protocol`.
2. `ui/js/native/bridge.js`: `isNative`, `init()` (adds `body.native`, installs `receiveNativeMessage`, then calls `initializeNativeCommunication`), `send`, `sendBinary`, `on`.
3. `canvas.js`: in native mode no demo canvas; `<div id="viewport">` fills `.workspace-main`; `viewport_bounds` (rect × `devicePixelRatio`) from a `ResizeObserver`, `window.resize` and a resolution media query.
4. `app.css`: in native mode `body`, `#app`, `.middle`, `.workspace`, `.workspace-body`, `.workspace-main` are transparent; chrome keeps its own backgrounds.
5. Shell: decode UI frames with `fx_protocol::decode`; `viewport_bounds` → rounded physical rectangle → composite offset/scale (computed from the current window size at draw time) and a `#3a3a3a` test texture with a 1 px red border, rebuilt when the size changes.

## What was done

As planned. Two findings on the way:

* **Full-screen mode (`F` twice) collapsed the whole workspace to 4 px**, in the browser too. `#app` was a grid with a fixed first track (`var(--topbar-h)`); hiding the title bar and options bar auto-placed the middle area into that 29 px track. Rows are now placed explicitly (`grid-row` per bar) and sized `auto auto 1fr auto`, with the title bar keeping its height itself.
* **A page reload inside the app can serve stale CSS** from CEF's cache. Restarting the app (the documented dev loop) is fine; a DevTools reload needs "disable cache".

Browser mode is unchanged: `bridge.send` drops messages there until M0-T05 adds the mock engine.
