Agent: Claude  ·  Branch: `task/M0-T06-engine`  ·  Status: done, **acceptance not measured yet** (Rob tests later)

## Plan (written before coding)

1. `fx-render::test_pattern` (+ `.wgsl`): full-screen pass into an `Rgba8Unorm` target — 256 px checker in document space, a line every 4096 px (≥ 3 screen px), cyan bounds, `#282828` outside. GPU tests read pixels back.
2. `fx-engine::view`: pure view state — fit on first viewport, wheel (pan / Shift horizontal / Ctrl-Alt zoom at cursor, 1.1 per notch), pan drags (middle button, Space + left, hand tool), `zoom:in/out/fit/100`, `set_zoom`. Unit-tested.
3. `fx-engine::engine`: engine thread, inputs in order, `view` messages throttled to 60 Hz, `hello` → `toast "Engine connected"`, unknown non-UI-local actions → toast.
4. `fx-engine::render`: render thread, newest request wins, double-buffered viewport textures, submits through `wgpu_sync::Queue`, sends `EngineOutput::ViewportFrame`.
5. `EngineHandle::spawn(device, queue, sink)` / `send` / `shutdown` (also on drop).
6. `fx-app`: engine outputs as `AppEvent::Engine`; bounds → engine `ViewportResized` + input router; `direct_input` → router; `input.rs` routing ported from Graphite (viewport rect + direct input, drag keeps its route until release, Space tracked, tablet pressure/tilt, `time_us`); engine cursor shown while the engine owns the pointer.
7. UI (native): rulers, tab label and status zoom from `view`; `zoomTo` → `set_zoom`; zoom actions go to the engine; status-bar "Fit"/"Actual Pixels" go through actions.

## Deviations from the task card

1. `PointerInput::buttons` bits and the wheel units (notches, positive = away from the user) were undocumented in the skeleton; now documented (`fx_engine::view::BUTTON_*`). Pixel wheel deltas are converted at 120 px per notch in the shell.
2. Pointer *moves* over the viewport also go to the UI (as Graphite's observe-only events do), so chrome hover states clear; buttons and wheel go only to the engine.
3. `RUST_LOG` for the shell is `fotox=…` (binary crate name), for the engine `fx_engine=…`.
