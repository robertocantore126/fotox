## Deviations from the task card

- The card says "`vello_cpu` if its API is stable at the time, else
  `tiny-skia`". Reviewed at the time of the task, `vello_cpu` still documents
  "no stability guarantees" and the Linebender unified-API work was still in
  progress, so the fallback (`tiny-skia`) was chosen. Recorded consequence: the
  vector renderer's coverage is 8-bit (tiny-skia `Pixmap` is premultiplied
  RGBA8). Photoshop's own layer anti-aliasing is 8-bit, so this is acceptable;
  it is the one argument for revisiting Vello later.
