# M1-T05 — Mip generation

Agent: Claude  ·  Branch: `task/M1-T05-mips`  ·  Status: done; scheduling part moved to M1-T07

## What was done

* `fx_tiles::downsample_2x2` as documented: premultiplied RGBA average, gray box average, round-half-up in integer arithmetic (`u64`), one loop per format (no per-pixel format branch), empty/solid children filled without pixel reads, four identical uniform children → a filled tile directly. The four `M1-T05` spec tests are un-ignored with their assertions unchanged; 3 more tests (gray rounding, 8-bit premultiplied, transparent solid drops its colour).
* `TileBuffer::as_u16_mut` (next to `as_u16`, same safety argument) — the only change to Claude-core code, needed to write 16-bit tiles without per-sample byte conversion.
* `fx_engine::mips`:
  * `ensure_mip(image, store, level, tx, ty)` — collects, per level, exactly the tiles that are dirty *or evicted* (a `Derived` handle that is no longer hot) below the requested one, computes them level by level on rayon, commits with `set_derived_slot`. If a tile is evicted between being computed and being read, it restarts (≤ 4 times), recomputing only what is missing.
  * `ensure_all_mips(image, store)` — every dirty tile, level 1 upwards (idle work, `bench mips`).
  * Children outside the grid are `Empty`; all-empty → `Empty`, all-same-solid → `Solid` with no pixel work; uniform results collapse; data is stored as `TileClass::Derived`.
  * 5 tests: empty pyramid, solid pyramid costs no tile memory, only the needed tiles are computed and cleaned, pixels equal `downsample_2x2` of the children, whole pyramid clean.
