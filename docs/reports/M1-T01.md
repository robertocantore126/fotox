# M1-T01 — `fotox-cli gen` and `info`

Agent: Claude  ·  Branch: `task/M1-T01-gen`  ·  Status: done; B1/B2 acceptance runs are Rob's

## What was done

* **`gen OUT.tif --width W --height H --bits 8|16 [--seed N]`** (`src/gen.rs`). Every pixel is a pure function of `(x, y, seed)`: three large gradients (one per channel, different directions), 4-octave value noise (periods 4096/2048/1024/512 px, smoothstep-interpolated lattice, splitmix64 hashing) and ±1.5 % per-pixel grain. Bands of 256 rows are generated with every core (rows in parallel) and handed to a writer thread through a channel of capacity 2 → ≤ 4 bands in memory (B1: 46 MB per band). Progress every 10 %, final MB/s.
* **Hand-written streaming TIFF writer** (`src/tiffw.rs`, ~200 lines): RGB, 8/16-bit, uncompressed strips of 256 rows, little-endian, BigTIFF automatically when the file cannot stay below 4 GiB (always for B1), classic otherwise. No timestamp or software tag, so the output depends only on the pixels. The `tiff` crate was not used: it is not needed for writing uncompressed strips, and writing by hand keeps every byte deterministic.
* **`info FILE`** (`src/info.rs`): header + first IFD only (instant on 5 GB): size, samples/bits/photometric, extra samples (alpha kind), compression, strip or tile layout, BigTIFF, byte order, ICC profile (size), file size. Both byte orders, classic and BigTIFF.
* `gen` is a reserved word in Rust 2024: the module is `r#gen` (file `gen.rs` as the card says).
