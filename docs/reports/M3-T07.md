## What was done

* Added the workspace dependency `jpeg-encoder = "0.6"` (D-029) and used it in
  `fx-io`.
* `ExportFormat::Jpeg` (`.jpg` / `.jpeg`), `JpegChroma::{Full, Half}` (4:4:4 /
  4:2:0), and `ExportOptions { … quality, chroma }`.
* `write_jpeg`: JPEG has no streaming encoder, so it accumulates the 8-bit RGB
  image (flattened onto white, since JPEG has no alpha) band by band and encodes
  once. Sides above 16 384 px are refused with a clear message (~800 MB buffer).
* `fx-engine::export::options_for` forces 8-bit and disables alpha for JPEG.
