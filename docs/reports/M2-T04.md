## What was done

1. **Brightness/Contrast** baked as a LUT (`adjust::brightness_contrast`, the `todo!` replaced). Parameters in the dialog's units (brightness −150..150, contrast −100..100):
   * legacy: `(x − 0.5)·k + 0.5 + brightness/255`, slope `k = 1 + c` (c < 0) or `1/(1 − c)` (c ≥ 0), `c = contrast/100`; clipped.
   * modern: never clips — gamma `x^(1/g)`, `g = 2^(brightness/100)`, then the S-curve `x^p / (x^p + (1−x)^p)` through (0.5, 0.5), `p = 1 + 2c` / `1 + 0.8c`.
2. **Hue/Saturation** (master), per pixel:
   * CPU `adjust::hue_saturation` (used by `reference.rs`, the `todo!` replaced) and the same math in f32 in `composite.wgsl` (`K_ADJUST_HUESAT = 2`, `hue_saturation` / `rgb_to_hsl` / `hsl_to_rgb`); `compositor.rs` encodes `GpuOp.params = [hue, saturation, lightness, colorize]` and no longer rejects it in `check_supported`.
   * Normal: HSL, hue rotated by `hue`°, saturation scaled by `1 + saturation/100` (greys stay grey), lightness kept. Colorize: hue/saturation replaced (0..360°, 0..100), HSL lightness kept. Then lightness blends to white (> 0) or black (< 0).
   * Test: `gpu/tests.rs::hue_saturation_and_brightness_contrast_match_the_reference` — a stack with Hue/Saturation (masked), Colorize at 50 %, Brightness/Contrast: GPU vs CPU max error 0.00092, 0 % of channels above 2/1024.
