# M1-T02 — Streaming TIFF import

Agent: Claude  ·  Branch: `task/M1-T02-tiff`  ·  Status: done; B1 speed/RSS measurement is Rob's (via `bench import`, M1-T10)

## What was done

* `import_file` sniffs the first 8 bytes (`II*\0`, `MM\0*`, `II+\0`, `MM\0+`; PNG and JPEG signatures are recognised and answered "arrives in M1-T09" until then). `sniff()` and `MAX_SIDE` are public.
* `fx-io/src/tiff.rs`, built on the `tiff` crate's per-chunk decoding:
  * 8/16-bit unsigned; Gray, Gray+alpha, RGB, RGBA; associated alpha (ExtraSamples = 1) → straight, rounded; strips or tiles; none/LZW/Deflate/PackBits; classic and BigTIFF. Everything else → `IoError::Unsupported` naming what is not supported (compression, planar, float samples, colour type, bit depth).
  * Units (a strip, or a row of tiles) are decoded **in parallel** in batches of ~2 bands (`map_init`: one decoder and file handle per rayon task), converted to RGBA of the document depth, then copied **in order** into an exact 256-row band; each full band is cut into tiles in parallel and inserted with `put_buffer` in order. Any strip height or tile size works (7-row strips, 80 × 32 tiles are tested). Memory: one batch + one band.
  * Pixels right of / below the image in the edge tiles are transparent.
  * ICC (tag 34675) → `ColorProfile::Icc`, none → `Srgb`. XResolution + ResolutionUnit (inch; cm × 2.54; "no unit" → default) → `ppi`, default 72.
  * Progress per unit; `false` cancels with `IoError::Cancelled` (the partial `TiledImage` is dropped).
* Tests (`tiff_tests.rs`, 9): RGB8 uncompressed; RGB16 LZW with 7-row strips; RGBA8 Deflate; Gray16 PackBits; BigTIFF Gray8 with ICC and cm resolution; Gray+alpha 16-bit **associated**, tiled 64 × 48; RGB8 tiled 80 × 32; unsupported CMYK / float / junk; cancellation. Each compares pixels exactly at tile corners and edges, and checks that pixels outside the image are transparent. Files the `tiff` encoder cannot produce (gray+alpha, associated alpha, tiles) are written by a small hand-made writer in the test.

## Findings

* The `tiff` crate reports gray/RGB with *associated* alpha as `Multiband`; the photometric tag disambiguates. WhiteIsZero with alpha stays unsupported (the crate does not invert it).
* The `tiff` encoder writes `SampleFormat` with one value per sample and a resolution of 1 with unit "none"; both are handled.
