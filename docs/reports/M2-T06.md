# M2-T06 — Layers and History panels, live (+ M2-T04 step 3)

Agent: Claude  ·  Branch: `task/M2-T06-panels`  ·  Status: done; 1 000-layer fluidity (S-check) and hands-on use are Rob's

## What was done

**`ui/js/native/layers-panel.js`** (used by `panels.js` in the app; the browser keeps the mock panels):

* Driven by `layers`, `history`, `thumbnail`, `active_document`. Nothing changes locally: every action is a document `command`, the next `layers` message shows the result.
* **Layers panel**: blend mode drop-down (Pass Through only for groups), Opacity and Fill (type a value, or drag the label to scrub; one command per animation frame), lock image pixels / position / all, and a **virtualised list** (fixed 30 px rows, only visible rows exist; groups can collapse — a panel-only state initialised from `expanded`). Each row: eye, expand arrow (groups), thumbnail (pixel / solid fill: from the engine's `thumbnail` frames, 64 px, on a checkerboard; groups and adjustments: icons), mask indicator, clipped arrow, name (double-click to rename; Enter / Escape / blur), blend and opacity when not default, lock icon. Click / Ctrl+click / Shift+click selection → `select_layers`. Drag a row above / below another, or onto the middle of a group to put it inside (on top) → `move_layer` with the "index after removal" semantics. Footer: add mask (reveal all), new fill/adjustment layer menu (Solid Color from the foreground colour, Brightness/Contrast, Levels, Curves, Exposure, Hue/Saturation, Invert), group (the selection if several, else a new empty group), new layer, delete.
* **History panel**: "Open" + every step; the current state highlighted, undone steps greyed; clicking a row undoes/redoes to it; step backward / forward buttons. Ctrl+Z / Ctrl+Shift+Z (existing) and **Ctrl+Alt+Z** (`hist:toggle`) added.
* **M2-T04 step 3**: double-click an adjustment layer's icon → its existing Fotox dialog (Brightness/Contrast, Hue/Saturation, Exposure), prefilled with the layer's parameters; every slider/checkbox change sends `set_adjustment` live; OK keeps it, Cancel restores the original. `dialogs.js` gained a generic hook for that (`values`, `onChange`, `onOk`, `onCancel` in `openDialog`'s overrides).

**Engine / protocol:**
* **Edit merging**: a repeat of the same edit — `set_layer_props` of the same layer touching the same fields, or `set_adjustment` of the same layer — within 1 s replaces the previous history step instead of adding one (undo + apply on the engine thread; a refused value puts the step back). Slider drags and live dialogs therefore make one step, like Photoshop.
* `LayerInfo` gained `locked_pixels`, `locked_position`, `adjustment` (adjustment layers), `fill_color` (solid fills), all `serde(default)`; `PROTOCOL.md` updated.
