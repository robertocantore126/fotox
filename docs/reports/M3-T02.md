## What was done

* `fx_core::Document::id_state()` / `with_id_state()` — expose the private
  `next_id` and `name_counters` so default names continue after a reopen
  (`"Layer 7"`), without giving `fx-core` any file concern.
* `fx_io::fxd::manifest`:
  * `Manifest { version, width, height, color, ppi, next_layer_id,
    name_counters, selected, layers, preview }`.
  * `LayerEntry` = every `Layer` field plus a flattened, `kind`-tagged
    `LayerKindEntry` (`pixel` with `offset`/`image`, `group`, `adjustment`,
    `solid_fill`), and `MaskEntry` (`enabled`, `linked`, `outside_value`,
    `image`).
  * `ImageEntry`/`LevelEntry`/`SlotEntry`: only **non-empty** slots; level 0 is
    authoritative, levels 1–2 are never stored, levels ≥ 3 are `derived: true`.
    Slots serialise as `[tx, ty, "s", r, g, b, a]` or `[tx, ty, "t", offset, len]`.
  * `to_manifest(doc, tile_ref)` — `tile_ref` maps a `TileHandle` to the chunk
    the save path wrote.
  * `manifest_to_json` / `manifest_from_json` (unknown fields ignored; the
    version is probed first so a future shape still gets a clear error) and
    `encode_manifest` / `decode_manifest` (zstd frame, D-025).
* The model lives in `fx-io`; `fx-core` stays free of file concerns (it only
  gained the two counters accessors).

The round-trip test builds a document with: a pixel layer (negative offset
`(-300, 40)`, `clipped`, `locked_pixels`, a **linked** mask), a solid layer
with an **unlinked** mask, a group containing a nested group (a solid child and
an adjustment child), one layer per adjustment kind (Brightness/Contrast,
Levels with non-default channels, Curves, Exposure, Hue/Saturation, Invert,
plus Invert nested) and a hidden, position-locked layer; it asserts the pixel
layer stores only levels `[0, 3]` with `derived` on level 3, JSON round-trips
with an unknown field added, and the zstd frame round-trips.
