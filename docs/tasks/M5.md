# M5 — Selections and painting

> **Approved by Rob (25 Sep 2026).** Decisions T00-1…T00-10 are accepted and
> recorded as D-040…D-049 in `docs/DECISIONS.md`.

Goal: select (marquee, lasso, polygonal lasso, magic wand, Select menu),
use selections (fill, delete, copy/paste, layer via copy, masks, limit
filters), and paint with a pressure-sensitive brush engine: brush, pencil,
eraser, mask painting, clone stamp, healing brush, spot healing.

Exit criteria: **S9** — a 500 px brush stroke on a 16-bit layer of B1 at
100 %: input → pixels ≤ 16 ms (`PERFORMANCE.md`), measured with the latency
statistic of M5-T11; plus (proposed):

| Id | Scenario | Target |
| --- | --- | --- |
| S13 | B1: magic wand, contiguous, tolerance 32, on a region of ~10 % of the image | selection ready ≤ 2 s; marching ants at fit ≤ 100 ms after |
| S14 | B1: feather a 20 000² rectangular selection by 50 px | ≤ 5 s, UI responsive |
| S15 | B1 at fit: a 500 px stroke across the whole view | visible while drawing (level-L update) ≥ 30 fps |

Read first: `docs/ARCHITECTURE.md` §2.2 (input routing), §5 (brush strokes
are commands); `crates/fx-engine/src/{lib.rs,view.rs}` (`PointerInput`,
`ViewState::tool`); `crates/fx-ops/src/lib.rs`; `docs/tasks/HOWTO.md` R1a,
R1b, R5, R6, R8, R10; M4-T05 (filter framework — feather and heal reuse it); `docs/tasks/SNIPPETS.md` §3, §6, §7, §8, §9, §15, §15b, §17.

Order: T00 → T01 → T02 → T03 → T04 → T05 (selections); T06 → T07 → T08 → T09
(painting; can start after T02); T10 UI along the way; T11 last.

## M5-T00 — Decisions (Rob) — **done**

Each answer becomes a `D-0xx` line in `DECISIONS.md`. The bold answer is
Claude's recommendation. All ten answers below are accepted (D-040…D-049).

1. **Selection pixels** use the document's grey format (Gray8 / Gray16), like
   masks already do (`mask_image(…, doc.color.depth.gray_format(), …)`), with
   an integer offset like layers (moving a selection outline never rewrites
   tiles). **Yes.**
2. **Brush engine on the CPU** (rayon + a dedicated stroke thread), f32
   maths; GPU dabs only if S9 is missed. **Yes.**
3. **Stroke model** = Photoshop's: within one stroke, dabs build up coverage
   with *flow* in a stroke buffer, the buffer is applied to the layer with
   *opacity* as a ceiling and the brush *mode*. **Yes.**
4. **Eraser** always erases to transparency: Fotox has no special
   "Background" layer (an imported image's layer is a normal layer with
   position locked). **Yes.**
5. **Clone/heal source** = the document as it was when the stroke started
   (no feedback from the stroke into its own source); sample *Current Layer*
   or *All Layers*. **Yes.**
6. **Healing**: during the drag the healing brush shows the clone; at pen-up
   a Poisson blend over the stroke area (what Photoshop visibly does). Spot
   healing with "proximity match" (source chosen automatically); Content-Aware
   fill (PatchMatch) later. **Yes.**
7. **Pen input** through Windows Ink (`WM_POINTER`, what the winit fork
   reports as `TabletToolData`); WinTab is not supported. Rob checks that his
   tablet's driver has Windows Ink on. **Yes.**
8. **Blend maths for brushes**: the pure blend functions move from
   `fx-render::blend` to `fx-core::blend` (no GPU dependency) so `fx-ops` can
   use them; `fx-render` re-exports them. **Yes.**
9. **Clipboard**: internal (pixels stay in the tile store); the Windows
   clipboard gets a copy only below 8 192² px (CF_DIBV5, straight alpha) and
   pasting from it creates a layer. **Yes.**
10. **Lock transparent pixels** (Photoshop's third lock) — add it now (brush
    and fill respect it; it is one more `LayerPropsPatch` field and panel
    button)? **Yes.**

## M5-T02 — Viewport overlays — **done**

**Files** `crates/fx-render/src/{overlay.rs (new),gpu/viewport.rs,gpu/overlay.wgsl (new)}`,
`crates/fx-engine/src/render.rs` (`Frame::overlay`).

Everything the tools draw over the image: marching ants, lasso in progress,
brush outline, clone source crosshair, transform/crop handles (M6), guides
later. Drawn by the render thread in the viewport pass, after the tiles.

* `pub struct Overlay { pub items: Vec<OverlayItem> }` in **document
  coordinates**: `Polyline { points, closed, style }`,
  `Circle { centre, radius, style }`, `Handle { at, size_px }` (screen-sized
  squares), `Crosshair { at }`. Styles: `Ants` (black/white dashes, 4 px,
  animated), `Solid(colour)`, `Xor-like` (white line with a black 1 px halo,
  readable on any image).
* Rendering: tessellate to screen-space quads each frame (lines 1 physical
  px, halo 3 px) in `overlay.rs` (pure, tested), one draw call; dashes from a
  per-vertex arc length + a time uniform in the fragment shader.
* **Ants animate**: while an overlay with `Ants` is visible the render thread
  redraws at 8 Hz (a timer `Wake`), otherwise frames are still only drawn on
  change.
* `Frame` gains `overlay: Option<Arc<Overlay>>`; tools set it through the
  engine; the brush outline follows the pointer (hover moves update only the
  overlay: no composite work).

**Tests** tessellation of a square polyline at zoom 1 and 0.25 gives the
expected screen quads; a GPU test draws a 1-px line at a known place.

## M5-T03 — Selection core — **done**

**Files** `crates/fx-core/src/{selection.rs (new),command.rs,document.rs}`,
`crates/fx-ops/src/{raster.rs (new),morph.rs (new)}`,
`crates/fx-engine/src/selection.rs (new)` (ants contour).

* `Document::selection: Option<Selection>` with
  `pub struct Selection { pub image: TiledImage /* Gray, doc depth */, pub offset: (i32, i32) }`.
  0 = not selected, max = selected. `None` = no selection (everything is
  editable). Selection images have mips (derived), like layers.
* `pub enum SelectionShape { Rect { x, y, w, h }, Ellipse { x, y, w, h },
  Polygon { points: Vec<(f64, f64)> }, RowPixel { y }, ColumnPixel { x } }`,
  `pub enum SelectMode { Replace, Add, Subtract, Intersect }`.
* Rasterisers (`fx-ops::raster`, one tile at a time, only tiles the shape's
  bounding box touches): rectangle = exact area coverage of each pixel;
  ellipse (as a 256-segment polygon, finer for radii > 10 000 px) and polygon
  = **non-zero winding with exact area coverage** (accumulation-buffer scan
  conversion, as in font rasterisers). Anti-alias off = coverage ≥ 0.5 → 1.
* Combining per tile: Add = max, Subtract = min(a, 1 − b), Intersect =
  min(a, b); tiles untouched by the shape follow from the mode without
  reading pixels (Replace → Empty, Intersect → Empty, Add/Subtract → keep).
* Commands (R1): `Select { shape, mode, feather, anti_alias }`,
  `SelectAll`, `Deselect`, `Reselect` (restores the selection removed by the
  last `Deselect`; `OpenDoc` keeps it), `InvertSelection`,
  `ModifySelection { op: Expand(px) | Contract(px) | Border(px) | Smooth(px) | Feather(px) }`,
  `OffsetSelection { dx, dy }`. All undoable, labels as Photoshop ("Rectangular
  Marquee", "Deselect", "Feather"…). Selection changes are real history
  steps (Photoshop records them).
* Feather = Gaussian blur of the selection (M4-T06, σ = radius / 2, VERIFY);
  Expand/Contract = threshold at 50 %, Euclidean distance transform
  (Felzenszwalb–Huttenlocher, separable) within tile + apron r, re-anti-aliased
  1 px edge; Border(w) = Expand(w/2) − Contract(w/2); Smooth(r) = median-like:
  blur r then threshold 50 %.
* **Marching ants**: `fx-engine/src/selection.rs` extracts the 50 % contour
  (marching squares) from the selection at the **view level L**, visible tiles
  only, joins segments across tile edges into polylines (document space),
  caches per (selection generation, L, tile) and hands the overlay to T02.

**Tests** rect selection at fractional coordinates: exact edge coverage; ellipse
area within 0.1 % of πab; polygon (a star, self-intersecting) non-zero rule;
Add/Subtract/Intersect truth table on two overlapping rects; Expand then
Contract by the same radius returns a convex shape unchanged (± 1 px edge);
feather of a rect is symmetric; contour of a disc selection is one closed
polyline; undo of every selection command.

## M5-T04 — Selection tools

**Files** `crates/fx-engine/src/tools/{marquee.rs,lasso.rs,wand.rs}`,
`crates/fx-ops/src/flood.rs (new)`.

* **Rectangular / Elliptical Marquee** (M), **Single Row / Column**. At
  press: Shift = Add, Alt = Subtract, Shift+Alt = Intersect (also the option
  bar buttons). While dragging: Shift = square/circle, Alt = from centre,
  **Space held = move the marquee being drawn**. Style: Normal / Fixed Ratio /
  Fixed Size (options). Release → `Select` command. Click without drag with
  Replace mode = `Deselect`.
* **Lasso** (L): freehand points from pointer samples (drop points closer than
  0.5 screen px), closes on release. **Polygonal Lasso**: click adds a point,
  Backspace removes the last, Enter / double-click / click on the first point
  closes, Esc cancels; Alt while in freehand lasso switches to polygon
  segments (Photoshop). In-progress path = overlay polyline.
* **Moving the outline**: with a selection tool, drag *inside* the selection
  (no modifier) → `OffsetSelection` (overlay follows live; one command at
  release). Arrow keys move by 1 px, Shift+arrow by 10 px.
* **Magic Wand** (W): tolerance 0–255 (8-bit units, also for 16-bit docs),
  anti-alias, contiguous, sample all layers. Colour distance = max over
  R, G, B of |c − seed| (VERIFY; Photoshop also counts alpha). Contiguous
  flood fill (`fx-ops::flood`): a queue of (tile, seed spans); inside a tile a
  scanline fill; spans leaving the tile become seeds of the neighbour; the
  output selection tiles are the visited set (no document-sized bitmap).
  Non-contiguous: every tile thresholded independently on rayon. *Sample All
  Layers* composites the level-0 tiles it visits (`ctx.ops.composite`,
  cached for the operation).
* Quick Selection / Object Selection / Magnetic Lasso: out of scope (toast).

**Tests** drive each tool with synthetic pointer sequences and check the
command; wand on a two-colour image with a gradient boundary: tolerance 0
selects one exact colour, contiguous stops at a separating line, spans across
tile edges are followed (a spiral that crosses tiles many times).

## M5-T05 — Using the selection

**Files** `crates/fx-core/src/command.rs`, `crates/fx-engine/src/{ops.rs,engine.rs,clipboard.rs (new)}`, UI menus/dialogs.

* Every pixel command respects the selection (R1a implementations get the
  `Selection`): strokes are multiplied by it, filters `lerp` with it (M4-T05),
  fills are limited to it.
* `Command::Fill { layer, source: Foreground | Background | Color([u16; 4]) | Gray50 | White | Black, mode, opacity, preserve_transparency }`
  (Edit ▸ Fill, Shift+F5; Alt+Backspace fg, Ctrl+Backspace bg — Shift adds
  preserve transparency). `Command::Clear { layer }` (Delete / Backspace):
  alpha × (1 − selection).
* Layer via Copy (Ctrl+J) / via Cut (Shift+Ctrl+J) with a selection: the
  selected pixels (× selection) to a new layer above, same offset (the M2
  `layer:duplicate` fallback stays for no selection).
* Masks: `MaskFill::RevealSelection` (exists) and a new `HideSelection`;
  Layer ▸ Layer Mask ▸ Reveal/Hide Selection (`mask:reveal-sel`,
  `mask:hide-sel`), and the panel's mask button with a selection = Reveal
  Selection (Alt = Hide).
* **Clipboard** (T00-9): `clip:copy` (selected pixels of the active layer,
  or the whole layer), `clip:copy-merged` (composite), `clip:cut`,
  `clip:paste` (new layer; same document position if it is visible, else
  centred in the view), `clip:paste-special` ▸ Paste in Place. The clipboard
  holds a `TiledImage` + offset + depth (convert 8↔16 on paste into another
  document).
* Crop to selection (`img:crop`) waits for M6 (Crop).

**Tests** fill inside an elliptical selection: inside = colour, outside
untouched, edge = coverage-weighted; clear on a partially selected tile; copy
+ paste in place reproduces the pixels at the same position; paste into an
8-bit document from a 16-bit one converts with rounding.

## M5-T06 — Brush engine (`fx-ops::brush`)

**Files** `crates/fx-ops/src/brush/{mod.rs,tip.rs,path.rs,stroke.rs}`,
`crates/fx-core/src/{blend.rs,stroke.rs (new)}` (T00-8: the pure blend maths
move here).

* **Tip**: round, `diameter` px (1–5000), `hardness` 0–1, `roundness` 0–1,
  `angle`. Profile: coverage 1 for r ≤ h·R; for h·R < r < R a smooth fall-off
  `1 − smoothstep((r − hR)/(R − hR))` (VERIFY against Photoshop's curve);
  hardness 1 = a hard edge anti-aliased over 1 px; dabs under 4 px use 4×4
  supersampling so tiny brushes don't flicker.
* **Path**: dabs placed along the polyline of input samples every
  `spacing × current diameter` (spacing 1–1000 %, default 25 %), the remainder
  carried across segments and across event batches (so the result does not
  depend on how events were batched — test it); pressure/tilt/time
  interpolated linearly between samples.
* **Dynamics**: size × pressure (option "pressure for size", min 1 px),
  opacity and flow × pressure (option "pressure for opacity"); **Smoothing**
  0–100 % = pulled string of length `smoothing × diameter` (the dab follows the
  pointer at that distance; VERIFY feel); Airbrush = dabs keep coming at 30 Hz
  while the pen is down and still (engine timer).
* **Stroke buffer**: per touched layer tile a Gray16 coverage tile `S`
  (0…1): each dab `S = S + flow·d·(1 − S)` (build-up), where `d` is the dab
  coverage × selection. The layer result, always recomputed from the layer
  **as it was at stroke start**: `out = composite(mode, before, colour,
  alpha = opacity · S)` (straight colour, the blend formulas of
  `BLEND_MODES.md`; `Behind` and `Clear` modes: brush-only extras — out of
  scope). Recomputing from `before` makes opacity a true ceiling.
* **Targets**: layer pixels (RGBA) or the layer mask (Gray; colour = the
  foreground's luminance; eraser paints the background's). Locked pixels →
  refused at stroke start (toast). "Lock transparent pixels" (T00-10): alpha
  kept.
* Pure entry point shared by live and replay (R1b):
  `pub fn render_dabs(dabs: &[Dab], params: &BrushParams, before: &TiledImage, buffer: &mut StrokeBuffer, store) -> Vec<((u32, u32), TileBuffer)>`
  (returns the new layer tiles of the tiles those dabs touched).
* 8/16-bit: f32 maths, rounded once when writing a layer tile.

**Tests** a single dab at 100 % hardness has the exact disc area; spacing is
independent of event batching (same samples split 1× vs 7× → identical
tiles); flow 50 %, opacity 100 %: two overlapping passes in one stroke build up
to 75 %; opacity 50 % ceiling: never above 50 % however many passes; a stroke
crossing four tiles leaves no seam; Multiply brush on white = the colour.

## M5-T07 — Live strokes in the engine

**Files** `crates/fx-engine/src/{tools/brush.rs,stroke.rs (new),render.rs}`,
`crates/fx-core/src/{command.rs,history.rs}` (`Command::Stroke`, `History::record`).

* `Command::Stroke { layer, target: Pixels | Mask, tool: StrokeTool, brush: BrushParams, color: [u16; 4], samples: Vec<StrokeSample> }`
  where `StrokeSample { x, y, pressure, tilt_x, tilt_y, time_us }` are document
  coordinates **after smoothing** (replay needs no smoothing state).
  `StrokeTool::{Brush, Pencil, Eraser, Clone { source, offset, sample }, Heal { … }, SpotHeal}`.
* On pen-down: `before = doc.clone()`, set `hot_layer` (the compositor's prefix
  cache, M2-T05, so only the ops above the layer are recomputed), start a
  **stroke thread** (one per stroke, reused).
* Pointer moves are coalesced per frame: the engine turns the new samples into
  dabs (T06 path), sends them to the stroke thread, which renders them
  (`render_dabs`, tiles in parallel) and returns the new tiles; the engine puts
  them in a working copy of the layer (`put_buffer`) and publishes a snapshot.
* **Mips while painting**: for the view level L > 0, the touched tiles' mip
  ancestors up to L are recomputed right away (only those, `ensure_mip`), so
  the stroke is visible at fit (S15).
* Pen-up: last dabs, then `History::record(before, "Brush Tool")`; the command
  is kept for macros. **Spec test**: `Command::apply` of the recorded command
  on `before` == the live result, tile by tile.
* Esc during a stroke: nothing (Photoshop ignores it); undo right after works.

## M5-T08 — Eraser, pencil, clone stamp, healing, spot healing

* **Eraser** (E): `out.alpha = before.alpha · (1 − opacity·S)`; on a mask
  target paints the background colour. **Pencil** (B flyout): hardness 1, no
  anti-aliasing (coverage ≥ 0.5 → 1).
* **Clone Stamp** (S): Alt+click sets the source point (overlay crosshair
  follows the brush during the stroke); Aligned on = fixed offset for the
  whole session, off = offset restarts at each stroke; Sample: Current Layer /
  All Layers (composite of `before`). Dab colour per pixel = source pixel at
  `p − offset` (bilinear at sub-pixel positions), then the normal stroke model.
* **Healing Brush** (J flyout): the stroke is a clone; at pen-up, for the
  stroke's covered area (S > 0) solve per channel `Δf = Δsource` inside,
  `f = before` on the boundary (Poisson, multigrid V-cycles on the stroke's
  bounding box — memory ∝ stroke area), result `lerp(before, f, S)`. Committed
  as part of the same history step. Progress only if > 300 ms.
* **Spot Healing Brush** (J): no source; at pen-up choose the source offset
  among 8 candidates at 1.5 × diameter around the stroke (minimise the SSD of
  a boundary ring), then the healing solve.

**Tests** clone with offset (100, 0) reproduces the source pixels exactly in
a hard stroke; heal of a flat region with a darker patch copied from a
flat-but-brighter source gives the destination's level (no seam > 1/255);
spot heal removes a small dot on a smooth gradient (residual < 2/255).
