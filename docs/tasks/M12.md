## M12-T00 — Decisions (Rob)

1. **Smart Objects** (reverses D-055):
   - `LayerKind::Smart { source: SmartSource, transform: Mapping, filters:
     Vec<SmartFilter>, cache }`;
   - `SmartSource::Embedded(Arc<Document>)` is stored **inside the same
     `.fxd`** as a nested document (its tiles in the same container);
     `SmartSource::Linked(path)` points to a file.
   - The rendered pixels are derived tiles, computed at the requested level
     from the source's composite mips through the transform (M6-T01).
     Transforms are lossless.
   **Yes.**
2. **Smart Filters**:
   - the filter list is re-evaluated on the Smart Object's rendered pixels,
     per requested tile and level (the M4 filter framework with the level
     scaling it already has);
   - one filter mask for the stack;
   - per-filter blending options (mode, opacity).
   **Yes.**
3. **More filters.** Smart Filters with two filters (Gaussian Blur, Unsharp
   Mask) are thin. Add the common families (Blur: Box, Motion, Radial,
   Surface; Noise: Add Noise, Median, Dust & Scratches, Despeckle; Sharpen;
   Stylize: Emboss, Find Edges; Other: High Pass, Minimum, Maximum, Offset;
   Render: Clouds). **Either here as M12-T03b, or as a milestone of their own
   before M12 — Rob's call.**
4. **Artboards**:
   - an artboard is a top-level group with bounds and a background colour;
   - the document canvas becomes the union of the artboards (Photoshop's
     model);
   - export writes one image per artboard.
   **Yes.**
5. **Color Lookup formats**: `.cube` (1D/3D) and `.3dl`; `.look` / `.csp`
   later. The LUT is applied in the document's encoding as Photoshop does,
   with the table stored in the document. **Yes.**
6. **Slices export**: File ▸ Export ▸ Export As (slices) writes PNG / JPEG /
   WebP (WebP if the formats milestone has it) per slice, with names. HTML
   output is not done. **Yes.**

## M12-T01 — Smart Object core

**Files**
- `crates/fx-core/src/{layer.rs,smart.rs (new),command.rs}`
  (`ConvertToSmartObject`, `RasterizeSmartObject`);
- `crates/fx-render/src/program.rs` (a Smart layer is a derived-tile layer);
- `crates/fx-engine/src/{smart.rs (new),render.rs}` (`SmartRequest` next to
  `MipRequest` / `VectorRequest`);
- `crates/fx-io/src/fxd/{manifest.rs,save.rs,open.rs}` (nested documents).

**What to build**
- Convert to Smart Object (from one or several layers: they become the
  embedded document, with the selected layers' union as its canvas).
- The rendered tiles at level L are resampled from the source composite's
  level L′ that the transform's scale asks for (M6-T01's rule).
- Free Transform on a Smart Object changes its `transform` (instant, lossless,
  as for shapes, M6-T04).
- Rasterize. Duplicate shares the source (Photoshop's "New Smart Object via
  Copy" does not; both exist).
- Place Embedded (M7-T03) now makes a Smart Object.

**Tests**
- Scaling down 10× then up 10× is exact (the source is untouched).
- A Smart Object at level 2 equals the rasterised layer's level-2 mip within
  2/255.
- A nested document round-trips through `.fxd`.
- Opening is lazy for the nested tiles too.

## M12-T02 — Edit Contents and linked Smart Objects

**Files**
- `crates/fx-engine/src/{documents.rs,engine.rs}` (a child document tab bound
  to its parent);
- `crates/fx-core/src/smart.rs`.

**What to build**
- Edit Contents opens the source in its own tab. Saving it (Ctrl+S in that
  tab) updates the parent: a new source, the derived tiles invalidated, and a
  history step in the parent, "Edit Contents".
- Linked Smart Objects:
  - Place Linked makes one;
  - the file is watched (mtime) and "Update Modified Content" re-reads it;
  - "Relink" and "Embed Linked" work.
- Replace Contents.

**Tests**
- Edit → save → the parent shows the change and one undo restores the old
  source.
- A linked file changed on disk triggers the update prompt.

## M12-T03 — Smart Filters

**Files**
- `crates/fx-core/src/smart.rs` (`SmartFilter { params, enabled, blend,
  opacity }`, the filter mask);
- `crates/fx-engine/src/smart.rs`;
- `ui/js/native/layers-panel.js` (the filter rows under the layer).

**What to build**
- Filter ▸ Convert for Smart Filters. Any filter applied to a Smart Object
  becomes a Smart Filter row: toggle, double-click to edit (the live preview
  of M4-T05), blending options, drag to reorder, delete.
- Evaluation per requested tile and level (T00-2). The apron of a filter is
  scaled to the level, as in M4.

**Tests**
- A Smart Filter equals the destructive filter on the rasterised layer (level
  0, within rounding).
- Disabling it restores the pixels.
- The filter mask limits it.
- Re-ordering two filters changes the result as expected.

## M12-T04 — Layer styles: the other five and advanced blending

**Files**
- `crates/fx-core/src/styles.rs`;
- `crates/fx-render/src/styles.rs`;
- `crates/fx-render/src/gpu/composite.wgsl`;
- the style dialogs (mocks today).

**What to build**
- Bevel & Emboss: Inner / Outer Bevel, Emboss, Pillow; Smooth / Chisel;
  depth, direction, size, soften; shading (angle, altitude, gloss contour,
  highlight / shadow modes); Contour and Texture sub-sections. The height
  field is the distance transform of the alpha (M5-T03), shaded by a light
  vector.
- Satin, Inner Glow, Gradient Overlay (M8-T03), Pattern Overlay (M8-T06).
- Contours (curves on the effect's ramp) for Drop / Inner Shadow and the
  glows.
- Advanced blending: Blend If (this layer / underlying, with split sliders),
  Knockout (None / Shallow / Deep), Blend Interior Effects as Group, Blend
  Clipped Layers as Group, Transparency Shapes Layer, Layer Mask Hides
  Effects.
- Global Light as a document setting. Copy / Paste / Clear Style.

**Tests**
- Bevel of a square: the lit and shadowed sides by the light angle.
- Blend If 0–128 on the underlying hides the layer over bright pixels.
- GPU = CPU for every new op (the M2 differential harness).

## M12-T05 — Color Lookup and Selective Color

**Files**
- `crates/fx-core/src/layer.rs` (`Adjustment::ColorLookup { table, name }`,
  `Adjustment::SelectiveColor { … }`);
- `crates/fx-io/src/lut.rs` (new: `.cube`, `.3dl`);
- `crates/fx-render/src/adjust.rs`.

**What to build**
- Color Lookup as an adjustment layer and an image adjustment: load a
  `.cube` / `.3dl`, trilinear (tetrahedral if cheap) interpolation, the table
  stored in the document. Dither for 8-bit.
- Selective Color: Photoshop's nine colour ranges (Reds … Neutrals, Blacks),
  CMYK sliders, Relative / Absolute. `VERIFY` against Photoshop; the
  published formulas are cited.

**Tests**
- The identity LUT is exact.
- A 1D `.cube` equals the equivalent Curves.
- Selective Color's Reds −100 % cyan on pure red changes red only.

## M12-T06 — Layer Comps

**Files**
- `crates/fx-core/src/{document.rs,comps.rs (new)}`;
- `ui/js/native/comps-panel.js` (today "No layer comps yet").

**What to build**
- A comp records, per layer: visibility, position (offset / transform), and
  appearance (styles, blend, opacity, fill); optionally the Smart Object
  source state.
- New / Update / Apply / Delete, previous / next.
- File ▸ Export ▸ Layer Comps to Files writes one image per comp.

**Tests**: apply restores exactly what was captured; Update after a change
records the change.

## M12-T07 — Artboards and the Artboard tool

**Files**
- `crates/fx-core/src/{layer.rs,command.rs}` (`LayerKind::Artboard { bounds,
  background }`);
- `crates/fx-engine/src/tools/artboard.rs`;
- `crates/fx-render/src/program.rs` (clip to the artboard, its background).

**What to build**
- The Artboard tool (under Move): draw an artboard, resize it with handles,
  "+" buttons to add an adjacent one, presets (iPhone, A4…).
- Layers dragged into it are clipped to it and move with it.
- The canvas is the union (T00-4). Export per artboard (Export As).
- Guides and snapping (M7-T06) know artboards.

**Tests**
- A layer inside an artboard is clipped.
- Moving an artboard moves its layers.
- Export writes one file per artboard with the right bounds.

## M12-T08 — Slice and Slice Select, slice export

**Files**
- `crates/fx-core/src/document.rs` (slices);
- `crates/fx-engine/src/tools/slice.rs`;
- `crates/fx-engine/src/export.rs`.

**What to build**
- The Slice tool (draw user slices; auto slices fill the rest), Slices from
  Guides, Layer-Based slice.
- Slice Select (move, resize, divide, options: name, URL-free).
- Export writes each slice as an image (T00-6), named after the slice.

**Tests**: slices tile the canvas with auto slices; export writes the right
rectangles.
