## M10-T00 — Decisions (Rob)

1. **Path model.** It is the same `Path` for document paths, shape outlines,
   vector masks and type on a path:
   - `Path { subpaths: Vec<Subpath { closed, anchors: Vec<Anchor { pos, in,
     out, smooth }> }>, ops: Vec<PathOp> }`;
   - `PathOp` is Combine / Subtract / Intersect / Exclude per subpath, as in
     Photoshop.
   `PathEl` (M6-T06) converts losslessly. **Yes.**
2. **Boolean path operations** (Merge Shape Components, the path operations
   when rasterising) need a polygon-clipping library on flattened curves.
   Candidate: **`i_overlay`** (pure Rust, MIT). New dependency →
   DECISIONS. **Yes, unless Rob prefers curves kept as curves (then the only
   candidate is heavier).**
3. **Vertical type.** Parley lays out horizontally:
   - vertical lines are laid out as horizontal runs rotated −90°;
   - CJK glyphs stay upright; Latin is rotated, with "Standard Vertical Roman
     Alignment" as Photoshop's option.
   **Yes (say it is an approximation of full vertical OpenType layout).**
4. **Custom shapes library**: Fotox JSON (paths) plus the `.csh` import of
   Photoshop's legacy custom shapes when feasible (a documented format:
   later). **Fotox JSON only in M10.**

## M10-T01 — Paths and the Paths panel

**Files**
- `crates/fx-core/src/{path.rs (new),document.rs}` (`Document::paths`, the
  Work Path);
- `crates/fx-core/src/command.rs` (`AddPath`, `SetPath`, `DeletePath`,
  `RenamePath`, `PathToSelection`, `SelectionToPath`, `FillPath`,
  `StrokePath`);
- `crates/fx-io/src/fxd/manifest.rs`;
- `ui/js/native/paths-panel.js` (today a mock).

**What to build**
- Work Path, which is replaced by the next drawing, and saved paths.
- Path to selection (feather, anti-alias, the four modes) rasterises
  per tile.
- Selection to path: contour tracing (M5's ants) → curve fitting with a
  tolerance (Schneider's algorithm).
- Fill Path with the foreground / a pattern; Stroke Path with any brush tool:
  the path is fed to the M5 brush engine as a stroke, with or without
  simulated pressure.
- Paths are overlay-drawn: anchors, handles, the outline.

**Tests**
- A path round-trips through `.fxd`.
- Selection → path → selection is within a pixel of the original.
- Stroke Path with the Brush equals painting the same points.

## M10-T02 — Pen tool (P)

**Files**
- `crates/fx-engine/src/tools/pen.rs`.

**What to build**
- Click = corner anchor, drag = smooth anchor with symmetric handles.
- Alt:
  - Alt-drag a handle breaks the symmetry;
  - Alt-click an anchor converts it.
- Ctrl temporarily switches to Direct Selection; a click on the first anchor
  closes the path; Rubber Band previews the next segment.
- Mode (option bar): Path / Shape (makes a shape layer with the path) /
  Pixels (fills on the layer, like Photoshop's Fill Pixels).
- Auto Add/Delete: a click on a segment adds an anchor, a click on an anchor
  deletes it.
- Path operations (Combine / Subtract / Intersect / Exclude) for new
  subpaths.

**Tests**
- A scripted sequence of clicks and drags builds the expected anchors and
  handles.
- Closing works.
- Shape mode adds a shape layer.
- Alt breaks the symmetry.

## M10-T03 — Curvature Pen

**Files**
- `crates/fx-engine/src/tools/pen.rs` (a curvature mode).

**What to build**
- Clicks place points and the curve through them is computed as a smooth
  interpolating spline (Photoshop's curvature pen: Catmull-Rom-like, handles
  derived from neighbours).
- A double-click makes a corner point, a drag moves a point, Delete removes
  one.

**Tests**: three clicks give a smooth curve through the three points;
a double-clicked point is a corner.

## M10-T04 — Freeform Pen (and Magnetic)

**Files**
- `crates/fx-engine/src/tools/pen.rs` (a freeform mode).

**What to build**
- A freehand drag → curve fitting (the T01 fitter) with Curve Fit in pixels.
- The Magnetic option reuses M9-T07's live-wire; its Width / Contrast /
  Frequency come from the option bar.

**Tests**: a freehand circle fits within Curve Fit of the input points with a
handful of anchors.

## M10-T05 — Anchor tools, Direct Selection, Path Selection on paths

**Files**
- `crates/fx-engine/src/tools/{path_select.rs,direct_select.rs,anchor.rs}`.

**What to build**
- Add Anchor Point (splits a segment at the click, keeps its shape: de
  Casteljau).
- Delete Anchor Point (refits the neighbour handles).
- Convert Point (a click = corner, a drag = smooth).
- Direct Selection:
  - select anchors (click, Shift, marquee) and move them or their handles;
  - the arrows nudge;
  - it works on paths, shape layers and vector masks.
- Path Selection on paths: select / move whole subpaths, Align / Distribute /
  Arrange of subpaths, Combine (Merge Shape Components, T00-2).
- Editing a shape layer's outline turns a live shape into a path shape, with
  Photoshop's warning.

**Tests**
- Adding an anchor does not change the curve (sampled points equal).
- Delete then refit stays within a tolerance.
- Direct selection moves one anchor only.
- Merge Components of two overlapping rectangles gives one outline.

## M10-T06 — Vector masks

**Files**
- `crates/fx-core/src/layer.rs` (`Layer::vector_mask: Option<VectorMask {
  path, enabled, feather, density }>`);
- `crates/fx-render/src/program.rs` (a vector mask is a derived coverage image
  like a shape, multiplied with the pixel mask);
- `ui/js/native/layers-panel.js` (a second mask thumbnail).

**What to build**
- Layer ▸ Vector Mask ▸ Reveal All / Hide All / Current Path.
- Ctrl-click a thumbnail = load as selection. Rasterise the vector mask.
- Properties: Density, Feather. The feather is a blur of the coverage at the
  requested level, distances × 2⁻ᴸ, as the filters do (R6).

**Tests**
- A vector mask at level 2 equals the level-0 coverage downsampled within
  2/255.
- It combines with a pixel mask by multiplication.
- It round-trips through `.fxd`.

## M10-T07 — Shapes: Triangle, Custom Shape, live shape properties

**Files**
- `crates/fx-core/src/vector.rs` (`VectorShape::Triangle`, `Custom`);
- `crates/fx-engine/src/tools/shape.rs`;
- `ui/js/native/shapes-panel.js`.

**What to build**
- The Triangle tool (with corner radius, Photoshop 2021+).
- Custom Shape: from the Shapes library (T00-4); Edit ▸ Define Custom Shape
  from a path.
- Live Shape Properties in Properties: W / H / X / Y, corner radii, sides,
  star ratio.
- Stroke options: alignment, caps, joins, dashes (the renderer already takes
  them), arrowheads for the Line tool.
- Fill and stroke with a gradient (M8-T03) or a pattern (M8-T06).

**Tests**
- A triangle's corners.
- A custom shape round-trips.
- A dashed stroke's dash lengths.
- A gradient fill equals the gradient renderer clipped to the shape.

## M10-T08 — Type completion

**Files**
- `crates/fx-core/src/text.rs`;
- `crates/fx-render/src/text.rs`;
- `crates/fx-engine/src/tools/type_tool.rs`;
- `ui/js/native/{character,paragraph}-panel.js`.

**What to build**
- The Vertical Type tool (T00-3).
- The Horizontal and Vertical Type Mask tools: the typed text becomes a
  selection on commit, never a layer.
- Type on a path (point text flowing along a path, M10-T01), and inside a
  closed path (area text).
- Warp Text: the D-053 patch, applied to the glyph outlines losslessly, with
  the preset styles (Arc, Arch, Bulge, Flag, Wave, Fish, Rise…).
- Live Character and Paragraph panels: tracking, kerning, leading, baseline
  shift, faux bold / italic, all caps, small caps; alignment, justification,
  indents, spacing before / after.
- Type ▸ Convert to Shape, Create Work Path.

**Tests**
- Vertical text's glyph positions.
- A type mask gives the glyph coverage as a selection.
- Text on a circle has its baseline on the circle.
- A warp preset is stable (glyph outline hashes).
- Convert to Shape equals the rendered text.
